# 第二批完成情况：价格参考

本地实现已完成，线上网站尚未更新。价格数据覆盖11/85个地点；剩余74个保留待核实。本批没有接入实时菜单、自动报价或大众点评接口。

## 页面变化

- 地点列表卡片：直接展示已有餐饮人均参考或普通门票价格。
- 地点详情：增加费用涵盖范围、不包含项目、来源链接、核查日期和适用条件；有学生票时单独说明。
- 自选行程的地点选择与行程站点：展示同一套价格数据，避免各处不一致。
- 行程结果：增加已知站点费用小计、已有参考的站点数和缺价站点数。小计不代表完整预算，不包含交通、未知费用、购物和额外项目；人民币和港币分别显示，不自动换算。
- 已有路线的原预算保持原数据，新增小计只用于自选地点行程。

## 更新与验证

- scripts/update-price-references.py：默认读取原项目已有高德快照，生成 prices.js 与 docs/PRICE_IMPORT_AUDIT.json；不需要新密钥。
- 如以后选择实时刷新，可显式使用 --live，在本地通过环境变量 AMAP_API_KEY 或隐藏输入提供自己的授权密钥。该路径本次没有实际调用，不宣称已完成实时接口验收。密钥不写入网页。
- scripts/verify-price-import.py：6项测试通过，覆盖错误分店、区域参考点、无效或冲突金额、场馆人均误作门票、错误币种与历史日期。
- scripts/verify-prices.mjs：价格显示、免费与未知区分、学生票、重复站点去重、部分费用与多币种汇总检查通过；同时运行第一批全部逻辑回归及9个页面的 HTML 生成检查。
- 以上为逻辑检查；尚未完成真实浏览器布局和线上验收。没有新增跨用户后台或实时价格保证。
