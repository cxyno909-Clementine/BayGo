# 第一批修改结果

对应用户原需求第2、3、4、6项。日期：2026年11月15日。

## 已实现

- 地点已加入计划时，显示禁用的 Added to My Plan；不会重复添加。至少两站时，View My Route 直接进入路线结果；只有一站时引导继续选择。
- 自选路线页增加搜索，支持现有地点库的英文名、中文名、地区、地址、类别；已选地点单独显示、计数并可移除。搜索无结果或清空搜索不会清除已选地点，也不改变选择顺序。
- What to Prepare 使用逐项可勾选清单。以原材料说明拆分，不新增未经核实的要求。每项记录保存在本浏览器，刷新后恢复；旧“已阅读”总标记不自动当作所有材料已准备。
- 社区及生活指南的 Clear Filters 放入独立的次要操作区，和 Apply Filters 或 Search 分开；清空筛选不删除计划。社区的日期链接参数一并清除。

## 发布本批

1. 解压第一批更新包。
2. 在 GitHub 的 BayGo 仓库 Code 页选择 Add file → Upload files。
3. 将更新包内的 app.js、styles.css 上传到仓库最外层，替换原同名文件；docs 和 scripts 可一并上传用于保留记录。
4. Commit changes 到 main。既有 Pages 会按当前分支配置重新部署。
5. 部署成功后刷新网页；必要时用无痕窗口避免旧缓存。

先验证：搜索英文或中文地点、勾选两站、搜索其他地区、查看已选地点保留、生成路线、从地点详情查看已加入状态、逐项勾选材料并刷新、清空社区筛选。
